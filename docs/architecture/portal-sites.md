# 远程传输站点导航

> 发送页「远程传输」入口的实现细节：站点模型与校验、持久化与合并规则、页面交互与风险声明。
>
> 主文档 `docs/ARCHITECTURE.md` §8.1 / §8.2 保留入口概述。

## 1. 总览

- 入口：发送页方式区的云图标（`components/send/SendMethodZone.ets`，`send_method_portal`）跳转路由 `PortalPage`
- 应用只做站点导航：不承载网页内容、不代理文件、不发起网络请求，点击卡片经确认后交给系统浏览器打开
- 站点数据全部本地化：随包内置的推荐站点来自 `resources/rawfile/portal_sites.json`，用户站点、
  预设编辑覆盖与删除记录存于偏好存储

## 2. 站点模型与校验

`model/PortalSite.ets` 只含纯逻辑，不访问存储与网络，便于设备端用例直接覆盖。

| 字段 | 含义 |
|---|---|
| `id` | 站点标识；预设由配置给定，用户站点为时间戳 + 随机后缀 |
| `name` | 显示名称 |
| `url` | 站点地址 |
| `badges` | 特性徽标键序列 |
| `builtin` | 是否随包内置的预设 |
| `order` | 排序值，升序排列 |

校验与清洗规则：

- 地址只接受带主机名的 `http://` / `https://` 地址，拒绝空白与控制字符、拒绝 `userinfo`（`user:pass@host`），
  长度上限 512
- 名称去除控制字符与首尾空白，长度上限 40；空名称视为无效
- 徽标只保留已知键（免登录 / 需登录 / 点对点 / 大文件 / 临时有效），去重后按固定顺序输出
- 配置结构带 `schemaVersion`（当前为 1），版本不匹配整体丢弃；站点总数上限 30，同 `id` 重复条目只保留第一条

## 3. 持久化与合并

偏好键（`utils/PreferencesUtil.ets`）：

| 键 | 内容 |
|---|---|
| `portalUserSites` | 用户添加的站点，`{ schemaVersion, sites }` JSON |
| `portalPresetOverrides` | 用户编辑过的预设副本，按 `id` 覆盖内置条目 |
| `portalDismissedPresets` | 已删除的预设标识，逗号分隔 |
| `portalRiskAccepted` | 是否已确认首次进入的风险声明 |

`service/repository/PortalSiteRepository.ets` 首次访问时读取内置配置与上述偏好，按以下规则重建对外快照：

- 预设先应用编辑覆盖，再排除已删除项，最后拼接用户站点并按 `order` 升序
- 编辑预设以覆盖形式保存，`order` 沿用原值；删除预设记入忽略列表，日常使用中不会复活
- 删除用户站点直接从用户站点列表移除
- 「恢复默认」清空忽略列表与编辑覆盖、重新读取内置配置，保留用户站点；内置配置不可用时返回失败
- 站点变更经全局变更总线通知页面刷新

## 4. 页面交互

`pages/PortalPage.ets` 以卡片列表承载站点，每张卡片展示名称、特性徽标与地址（左侧为名称首字色块），
列表末尾固定一张添加卡片。

- 点击卡片：先弹出确认弹窗（展示站点名称与地址），确认后以 `ohos.want.action.viewData` 交给系统浏览器；
  启动失败提示「无法打开该站点」
- 长按或鼠标右键卡片：弹出编辑 / 删除菜单；删除二次确认
- 标题栏菜单提供「使用说明」与「恢复默认」，恢复默认二次确认
- 添加 / 编辑半模态：名称、地址与四个开关（需要登录、支持大文件、临时有效、点对点）；
  需要登录与免登录互斥，保存时由开关生成徽标序列；校验失败按名称、地址、数量上限、地址重复分别提示

## 5. 风险声明

首次进入页面（`portalRiskAccepted` 为假）弹出不可点击外部关闭的风险提示，列出三条要点：
站点内容与数据安全由第三方负责、传输的文件可能被站点保存或转发、站点规则可能变更。
选择「同意并继续」后立即落盘该标记；选择「不同意」或返回键均视为不同意并退出页面。
